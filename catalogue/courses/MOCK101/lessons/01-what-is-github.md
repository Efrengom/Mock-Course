## Why GitHub

GitHub hosts Git repositories online. Teams use it to share code, review each other's changes, and keep a history of every version of a project.

Watch this short introduction before the knowledge check.

https://www.youtube.com/watch?v=w3jLJU7DT5E

## Key ideas

- A **repository** holds a project's files and their full history.
- A **commit** records one set of changes.
- A **pull request** asks teammates to review a change before it is merged.
